# Plant Website

A modern, responsive plant website built with React, Vite, and Tailwind CSS.


## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- Lucide React

## Features

- Responsive navbar
- Hero section
- Featured plants
- Trending plants section
- Top selling plants section
- Customer reviews
- O₂ plant collection
- Interactive plant slider
- Manual previous/next navigation
- Dynamic slide indicators
- Scroll reveal animations
- Responsive design for mobile, tablet, and desktop
